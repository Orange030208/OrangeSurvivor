# 项目异味报告

生成时间: 2026-05-13 06:09:11 +08:00

审计范围: `Assets/Scripts`、`Assets/Tests/Editor`、`Assets/GameContent`、`Docs`、当前未提交工作区

审计原则: 以当前代码实际行为为准。上一轮报告中的 `MonoSingletonBase`、`GameInputService` 自动兜底、`PropertiesManager` 和 `AccessoryManager` 空引用问题在当前工作区已发生变化，本报告不再把已修复点当作当前缺陷。

## 总体结论

当前项目技术债等级为中高。核心问题不是语法错误，而是主流程类继续膨胀、运行时依赖隐藏在全局状态和事件总线中、内容池系统处于旧 Fact 链路与新 `ContentHistoryState` 并存的迁移状态。短期迭代仍能支撑，但继续新增武器、商店、奖励、波次和 UI 流程时，回归风险会快速上升。

## 最危险模块

1. `Weapon`：影响所有武器、命中、属性和表现。
2. `GameManager`：影响全局状态切换、暂停、UI、波次和玩家生成。
3. `UIManager`：影响所有页面、弹窗、遮罩和输入状态。
4. `ContentPoolRollService` / `ContentFactCollector`：影响升级卡、商店、掉落和刷怪池。
5. `ShopManager` / `RewardSelectionManager`：影响经济、奖励、暂停和内容历史。
