## 建议的下一步

最推荐先做 P0 的内容抽取系统迁移状态定版。原因是当前工作区已经出现 `ContentHistoryState`、`ContentRollContext`、旧 `FactDefinitionSO` 和旧 `ContentPoolRuntimeState` 并存；如果不先定边界，后续商店、升级卡、掉落和刷怪规则都会继续在两套状态之间摇摆。

## 重构风险控制

1. 每次只拆一个行为边界，不改变公开事件和资产字段。
2. 先为纯规则补 EditMode 测试，再移动代码。
3. 涉及 Unity 序列化字段时保留旧字段名或使用 `[FormerlySerializedAs]`。
4. 对 Manager 拆分先引入内部服务，不急着改场景 Prefab。
5. 每阶段结束后运行对应测试和残留扫描。
