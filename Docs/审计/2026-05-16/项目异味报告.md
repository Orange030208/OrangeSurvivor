# 项目异味报告

生成时间: 2026-05-16 06:07:24 +08:00

审计范围: `Assets/Scripts`、`Assets/Tests`、`Assets/GameContent`、`Docs`

结论: 当前技术债等级为中高。项目已有内容池、运行推进、武器运行时、UI 框架和数值同步等较完整模块，测试覆盖也比早期更好；但核心业务仍集中在少数巨型类、全局事件总线和静态运行时入口上。短期继续迭代可行，长期新增武器、波次、商店、奖励和设置项时，回归风险会持续上升。

## 影响范围

- 武器系统: 攻击周期、命中、投射物、表现、数值收益率。
- UI 系统: 页面、弹窗、设置、输入阻塞、对象池。
- 局内流程: 状态切换、波次、商店、奖励选择、波末清理。
- 内容池与数值同步: 商店池、掉落池、刷怪池、武器奖励池、Excel 同步。
- 全局通信: `GameEventBus`、`GameContentRuntime`、`RunProgressionRuntime`、`GameInput`、`UIManager.Instance`。
