# 项目异味报告

生成时间: 2026-05-18 06:10:15 +08:00

审计范围: `Assets/Scripts`、`Assets/Tests/Editor`、`Assets/GameContent`、`Docs`、`Packages/manifest.json`

事实来源优先级: 当前磁盘源码与资产状态 > `git status` > 历史审计报告 > 项目文档。第三方插件目录不计入本项目自研技术债。

## 总体结论

当前技术债等级: **中高**。

项目已经有内容池、波次、Buff、武器、UI 框架、输入、音频、局内推进和局部 EditMode 测试，说明并不是“无结构项目”。真正风险集中在三类区域:

- 少数核心大类仍承担过多职责，且其中 `Weapon.cs`、`GameManager.cs`、`ShopManager.cs`、`UIManager.cs` 也是近 30 天高频变更文件。
- 全局静态入口和场景查找兜底仍然支撑主流程，依赖边界不透明。
- JSON 数据导入工具已经进入工作区，并能直接删除 Unity 资产，但缺少删除确认门和回归测试。

当前工作区已有大量未提交变更，本报告只按当前磁盘状态审计，不回滚或修改这些变更。
