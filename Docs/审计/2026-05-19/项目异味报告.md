# 项目异味报告

生成时间: 2026-05-19 06:06:55 +08:00

审计范围: `Assets/Scripts`、`Assets/Tests/Editor`、`Assets/GameContent`、`Docs`、`Packages/manifest.json`。

事实来源优先级: 当前磁盘源码与资产状态 > `git status` > 昨日审计记忆 > 项目文档。第三方插件目录、Unity 生成文件、Library/Temp 不计入自研代码异味。

## 总体结论

当前技术债等级: **中高**。

项目不是无结构状态：已经有内容池、局内推进、波次、武器序列、UI 框架、Buff/Feature、对象池、音频与 EditMode 测试。但主要运行链路仍由少数巨型 MonoBehaviour 和静态全局入口串联，新增敌人、波次、奖励和 UI 时会持续触碰同一批高风险文件。

本轮工作区已有大量未提交变更，集中在敌人攻击范围、Cyber Orange 资源、数值资产、主菜单 UI 和波次资产。审计只按当前磁盘状态记录问题，不回滚、不覆盖这些变更。
