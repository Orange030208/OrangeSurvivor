# 项目音效枚举清单

## 目标

本文档只整理当前项目需要纳入 `AudioSfxKey` 的音效语义，便于后续统一配置到 `AudioBusSettingsSO`。

音效枚举应表达“项目中发生了什么声音事件”，不直接绑定具体音频素材名。具体 `AudioClip`、分组、音量、音高与并发限制仍由音频配置资源维护。

## UI 与流程音效

- `UiConfirm`：通用确认操作。
- `UiCancel`：通用取消或返回操作。
- `UiError`：无效操作、条件不满足、购买失败等错误反馈。

## 奖励卡音效

- `UpgradeCardReveal`：升级卡展示。
- `UpgradeCardCommonSelected`：普通升级卡被选择。
- `UpgradeCardRareSelected`：稀有升级卡被选择。
- `UpgradeCardEpicSelected`：史诗升级卡被选择。
- `UpgradeCardLegendarySelected`：传说升级卡被选择。

## 商店与背包音效

- `ShopPurchaseSucceeded`：商店购买成功。
- `ShopPurchaseFailed`：商店购买失败。
- `ShopRerolled`：商店刷新。
- `ItemEquipped`：装备武器或饰品。
- `ItemSold`：出售或回收物品。
- `WeaponMerged`：武器合成。
- `WeaponLevelUp`：武器等级提升。

## 掉落与宝箱音效

- `CoinCollected`：金币被收集。
- `ChestOpened`：宝箱打开动画开始或完成。

## 武器动作音效

- `Swipe`：通用快速挥动。
- `Slap`：通用近战拍击或直接伤害。
- `SwordSlash`：剑类普通挥砍。
- `SwordHeavySlash`：剑类重击挥砍。
- `DaggerStab`：匕首刺击。
- `StaffSwing`：法杖挥舞。
- `StaffProjectileLaunch`：法杖发射弹射物。
- `GunshotLight`：轻型枪械射击。
- `GunshotHeavy`：重型枪械射击。
- `EnergyShot`：能量枪或科技枪射击。

## 弹射物音效

- `GenericProjectileLaunch`：通用弹射物发射。

## 敌人与当前 Boss 音效

- `EnemyHurtGeneric`：通用敌人受伤。
- `EnemyHurtSkeleton`：骷髅类敌人受伤。
- `EnemyHurtStone`：石头类敌人受伤，用于 Golem 或石头材质敌人。
- `GolemMechaStoneBossPhaseChanged`：机甲石头 Boss 阶段切换。
- `GolemMechaStoneBossMelee`：机甲石头 Boss 近战攻击。
- `GolemMechaStoneBossShoot`：机甲石头 Boss 射击攻击。
- `GolemMechaStoneBossLaser`：机甲石头 Boss 激光攻击。
- `GolemMechaStoneBossShield`：机甲石头 Boss 护盾技能。

## 玩家与成长音效

- `PlayerLevelUp`：玩家升级并获得升级奖励点。

## 波次与关卡音效

- `WaveCountdownTick`：波次时间倒计时提示。
- `StageCompleted`：关卡完成。

## 整理原则

- 已有 `AudioSfxKey` 数值不改名、不重排，避免 Unity 序列化资源错位。
- 新音效只追加到合适语义分组。
- 没有项目系统或触发点支撑的声音不提前加入枚举。
- 同一类声音优先按玩法语义命名，不按素材文件名命名。
