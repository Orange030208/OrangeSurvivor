# 敌人、波次与终局压力

## 1. 波次总结构

新体系沿用 `Brotato` 风格的 20 波主循环。

建议波次时长直接对齐：

| 波次 | 时长 |
| --- | --- |
| 1 | 20 秒 |
| 2 | 25 秒 |
| 3 | 30 秒 |
| 4 | 35 秒 |
| 5 | 40 秒 |
| 6 | 45 秒 |
| 7 | 50 秒 |
| 8 | 55 秒 |
| 9-19 | 60 秒 |
| 20 | 90 秒 |

这条时长曲线很重要，因为它直接影响：

- `Harvesting` 的回收期
- 局内掉落密度
- 随时间成长类机制
- 最终 Boss 波的续航价值

## 2. 波次阶段目标

### 2.1 前期：1 到 5 波

目标：

- 建立第一套武器方向
- 让玩家开始为某个流派投入
- 不要求 build 完整，但要让“买武器还是买属性件”成为真实选择

敌人压力特点：

- 小怪为主
- 容错高
- 清群不足时会明显漏怪，但不该立即暴毙

### 2.2 中前期：6 到 10 波

目标：

- 主武器组进入初步成型
- 开始要求玩家补足生存或清图短板
- 让经济投资与纯战斗投资拉开区别

敌人压力特点：

- 密度明显上升
- 远程怪、快速怪开始进入主节奏
- 单体不足和群体不足都会暴露问题

### 2.3 中后期：11 到 15 波

目标：

- 构筑明确分流
- 开始出现精英或高危险节点
- 检查玩家是否真的围绕武器形成了合理属性组合

敌人压力特点：

- 更高密度
- 更强冲脸
- 更明确的远程压制
- 精英或节点怪要求玩家处理单体和走位

### 2.4 后期：16 到 19 波

目标：

- 检查终局可行性
- 迫使玩家承认自己构筑的短板

敌人压力特点：

- 小怪数量足以挤压走位
- 远程怪和高威胁特种怪共同存在
- 生存和清群任一短板都应明显放大

### 2.5 终局：20 波

目标：

- 终局是 Boss 检查，不是普通刷怪加长版
- 推荐采用 1 到 2 个 Boss 的终局结构

敌人压力特点：

- 90 秒长战斗
- 同时检验输出、生存、走位和持续恢复
- 若采用双 Boss，更能逼出 build 上限

## 3. 敌人设计原则

### 3.1 不靠单纯堆血

新体系的危险来源应拆成多轴：

- 数量
- 速度
- 近战追击
- 远程投射
- 精英技能
- Boss 区域封锁

如果某波压力不足，优先增加这些轴的组合，而不是先加血量。

### 3.2 小怪要承担清图检查

小怪不是背景板。

它们负责检查：

- 攻速是否足够
- 清群是否足够
- 路线规划是否合理
- 玩家是否因为过度贪经济而导致早期战斗弱势

### 3.3 精英和 Boss 要承担单体检查

精英和 Boss 主要检查：

- 是否有足够单体输出
- 是否有持续走位能力
- 是否有高压下的生存与恢复

## 4. 终局前推荐危险节点

如果项目需要接近 `Brotato` 的中后期结构，建议在 11 到 18 波安排 2 到 3 个高危险节点。

建议分布：

- 第一个节点：11 或 12 波
- 第二个节点：14 或 15 波
- 第三个节点：17 或 18 波

节点类型可在以下两类间切换：

- 精英波
- 大量敌群波

建议倾向：

- 前两个节点可以混合出现
- 最后一个节点应更偏精英或强单体压制

## 5. 终局 Boss 规则

建议对齐 `Brotato` 终局哲学：

- 20 波一定是 Boss 波
- 允许 1 到 2 个 Boss
- 若采用双 Boss，则应削弱单个 Boss 的纯血量，强化空间压迫与技能覆盖

Boss 波应重点检测：

- build 是否只会打小怪
- build 是否只有纸面伤害、没有真实移动能力
- build 是否只会堆回复、没有输出上限

## 6. 波次与经济的关系

波次设计必须与经济设计一起看，不能分开独立调。

例如：

- 更长波次会提高回复、吸血、成长类道具价值
- 更高密度会提高清群武器和掉落转化价值
- 更强远程压迫会提高速度和范围的相对价值

因此后续调波次时，必须同步回答：

- 这波是在奖励什么 build
- 这波是在惩罚什么 build

## 7. 当前项目推荐敌人分工

为贴近新体系，建议敌人 archetype 按职责划分，而不是只按皮相区分：

- 普通近战小怪：承担基础密度和走位压力
- 快速贴脸怪：惩罚低机动或贪经济 build
- 远程骚扰怪：惩罚纯站桩 build
- 重型高血怪：检验单体与穿甲能力
- 精英怪：阶段性 build check
- Boss：终局总检验

## 8. 波次验收标准

当波次设计正确时，应该出现以下现象：

1. 前 5 波足够让玩家定方向，但不会让任何方向轻松碾压。
2. 第 10 波左右，纯堆输出或纯堆经济的代价会开始被看见。
3. 第 15 波以后，清群弱、机动弱、单体弱的不同 build 会以不同方式出问题。
4. 第 20 波是真正的终局检查，而不是把普通怪继续刷更久。
