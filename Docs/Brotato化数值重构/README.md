# Brotato化数值重构文档入口

本目录用于承载项目新一轮数值重构的策划文档。

本轮重构的前提与旧体系不同：

- 当前项目没有角色系统，本目录不再以角色差异作为数值入口。
- 本目录不使用 `玩法数值规范.md` 里的 `BP`、旧预算锚点、旧价格预算或旧乘区价值表。
- 本目录采用 `Brotato` 风格的数值哲学：武器是核心，商店主导成长，升级是辅助成长，道具大量带正负词条，构筑围绕少数主轴属性形成。

## 使用范围

以下内容从本目录开始作为新数值体系的设计来源：

- 玩家基础属性目标
- 主属性与次属性定义
- 升级奖励强度档位
- 商店价格、刷新、锁定、武器合成与稀有度开放节奏
- 武器流派、道具流派、工程流派的设计规则
- 敌人、波次与终局压力口径

以下旧文档暂时不删除，但只保留“工程字段与既有实现参考”的用途，不再作为新强度依据：

- `Docs/玩法数值规范.md`
- `Docs/数值系统落地规范.md`

## 本目录文件说明

- `01_总设计原则.md`

- `02_属性体系与价值规则.md`

- `03_成长_商店_经济循环.md`
  - 定义升级、商店、武器合成、掉落与收获型经济。
- `04_武器_道具_构筑规则.md`
  - 定义武器流派、道具规则、正负词条与构筑主轴。

- `06_工程映射与迁移清单.md`
  - 定义当前工程要如何接入这套新数值体系。

## 本轮硬规则

1. 公开主属性按 `Brotato` 主轴组织，不再围绕旧 `Attack`/`DamageReduction`/`ShopPriceDiscount` 等项目内旧核心组织。
2. 商店和掉落的价值判断优先基于“升级档位等价物 + 槽位竞争 + 正负词条代价”，而不是旧 BP 预算。
3. 不再设计“纯福利型大池道具”为主的商店；主流道具默认允许负面词条存在。
4. 默认玩家没有角色模板加成；所有成长主要来自武器、升级、商店、掉落与局内经济。
5. 若后续需要保留旧系统中的个别字段，也必须先证明其能融入 `Brotato` 风格循环，而不是反过来让新体系迁就旧字段。
