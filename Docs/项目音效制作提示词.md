# 项目音效制作提示词

## 文档定位

本文档用于制作或生成当前项目 `AudioSfxKey` 对应的音效。它不是枚举设计文档，而是声音制作提示词文档：每个条目说明这个声音应该听起来像什么、由哪些层次组成、控制在什么时长、避免什么问题。

制作目标是得到一批可直接接入 Unity 的短音效。每个音效都应当能独立作为一次性 SFX 播放，并且适合在 2D 生存割草玩法中高频触发。

## 全局声音方向

项目整体听感建议：

- 类型：2D 生存割草、轻幻想、带少量科技武器。
- 节奏：反馈清晰、音头干净、短促直接，不拖沓。
- 色彩：UI 和奖励偏明亮；武器和敌人偏利落、有材质；Boss 偏沉重、机械、岩石。
- 混响：只允许短尾音，避免长混响、空间氛围和音乐化铺底。
- 人声：默认不要人声、喊叫、播报、拟人语音。
- 音乐性：不要旋律段落，不要背景音乐感，只做事件反馈音。
- 风格统一：可以用轻微魔法闪光、金币声、木质 UI、金属和能量层，但不要让单个音效像独立表演。

## 输出规格建议

- 文件格式：WAV 优先。
- 采样率：44.1 kHz 或 48 kHz。
- 位深：16-bit 或 24-bit。
- 声道：UI、拾取、短武器音可用 mono 或窄 stereo；奖励、Boss、关卡完成可用 stereo。
- 剪裁：文件开头不留静音；尾部只保留必要衰减。
- 峰值：避免削波，建议峰值不超过 -1 dBFS。
- 响度：同组音效响度应接近，Boss 和关卡完成可以略高，但不应压过所有战斗反馈。
- 变体：高频音效建议制作 2-4 个轻微变体，变体只改变音高、细节或瞬态，不改变语义。

## 统一负面约束

生成或制作所有音效时，应避免：

- 明显人声、角色喊叫、语音播报。
- 长环境底噪、持续风声、雨声、虫鸣、场景氛围。
- 明显音乐旋律、鼓点循环、长和弦铺底。
- 过长尾音、过重混响、强烈空间定位。
- 过度刺耳的高频、爆音、削波、失真。
- 过度写实血腥、骨肉撕裂、恐怖音效。
- 声音太满导致连续播放时混浊。

## UI 与流程音效

### UiConfirm

用途：通用确认操作，例如确认设置、确认选择、普通弹窗确定。

声音结构：

- 起音：短促、干净的木质或轻金属点击。
- 主体：轻微上扬的明亮提示音。
- 尾音：极短，快速收束。

制作提示词：

> 短促清脆的 UI 确认音，木质点击叠加轻微明亮铃音，积极、干净、轻快，适合 2D 游戏确认按钮，时长 0.15-0.35 秒，无人声，无长混响。

避免点：

- 不要做成购买成功的金币声。
- 不要太华丽，避免抢过奖励卡和升级音效。

### UiCancel

用途：取消、返回、关闭弹窗、放弃当前操作。

声音结构：

- 起音：偏低的轻点击或柔和拨片。
- 主体：轻微下行或收回感。
- 尾音：干净、短。

制作提示词：

> 简洁的 UI 取消音，轻微下行的木质点击或柔和拨片声，表达返回、撤销、关闭，短促克制，时长 0.15-0.3 秒，无错误警告感，无人声。

避免点：

- 不要像失败音或错误音。
- 不要用尖锐蜂鸣。

### UiError

用途：无效操作、条件不满足、无法购买、无法执行。

声音结构：

- 起音：短促低中频提示。
- 主体：轻微失谐或下行滑音。
- 尾音：快速消失，不拖尾。

制作提示词：

> 非刺耳的 UI 错误反馈音，短促低音提示叠加轻微失谐下行音，明确表示操作失败但不烦人，适合频繁 UI 反馈，时长 0.25-0.45 秒，无人声，无长混响。

避免点：

- 不要过度尖锐。
- 不要像系统报错警报。

## 奖励卡音效

### UpgradeCardReveal

用途：升级奖励卡展示、翻开、进入可选状态。

声音结构：

- 起音：纸牌滑动、翻开或轻微展开。
- 主体：轻微空气划过和小型魔法闪光。
- 尾音：短促明亮铃音，提示奖励出现。

制作提示词：

> 升级卡展示音，纸牌翻开和滑动声叠加轻微魔法闪光，明亮、轻盈、有奖励出现的感觉，适合多张卡连续展示，时长 0.35-0.7 秒，无人声，无长音乐尾音。

避免点：

- 不要按品质做得过强，因为所有卡展示共用一个音效。
- 不要太响，连续展示时不能吵。

### UpgradeCardCommonSelected

用途：普通升级卡被选择。

声音结构：

- 起音：清晰点击。
- 主体：短促确认铃音。
- 尾音：很短，保持朴素。

制作提示词：

> 普通升级卡选择音，简洁点击加轻微确认铃音，干净、明确、克制，奖励感较低，时长 0.2-0.4 秒，无人声，无夸张闪光。

避免点：

- 不要比稀有、史诗、传说更华丽。
- 不要听起来像错误或取消。

### UpgradeCardRareSelected

用途：稀有升级卡被选择。

声音结构：

- 起音：清晰点击或卡牌落位。
- 主体：明亮上扬铃音。
- 尾音：短促闪光。

制作提示词：

> 稀有升级卡选择音，卡牌确认点击叠加明亮上扬铃音，奖励感明显高于普通但仍短促，时长 0.25-0.45 秒，轻幻想质感，无人声。

避免点：

- 不要太厚重。
- 不要达到史诗或传说的层次。

### UpgradeCardEpicSelected

用途：史诗升级卡被选择。

声音结构：

- 起音：有分量的卡牌确认。
- 主体：多层明亮铃音和轻微能量闪光。
- 尾音：短尾，稍宽。

制作提示词：

> 史诗升级卡选择音，多层铃音、轻微能量闪光、较宽的奖励感，强调高价值选择但保持短促，时长 0.35-0.6 秒，幻想科技风格，无人声，无长旋律。

避免点：

- 不要做成关卡胜利音。
- 不要有过长和弦。

### UpgradeCardLegendarySelected

用途：传说升级卡被选择。

声音结构：

- 起音：高级卡牌落位或金属闪光。
- 主体：明亮和声、短促高光、轻微低频支撑。
- 尾音：华丽但快速收束。

制作提示词：

> 传说升级卡选择音，华丽短促的高亮和声、金属闪光和轻微低频支撑，表达顶级奖励选择，时长 0.5-0.9 秒，明亮、有分量、无语音、无长音乐段落。

避免点：

- 不要超过 1 秒太多。
- 不要像 BGM 开头或胜利音乐。

## 商店与背包音效

### ShopPurchaseSucceeded

用途：商店购买成功。

声音结构：

- 起音：金币或收银机的清晰瞬态。
- 主体：短促金币碰撞。
- 尾音：轻快确认铃音。

制作提示词：

> 商店购买成功音，金币碰撞和轻快收银反馈，积极、干净、有交易完成感，适合商店 UI，时长 0.3-0.6 秒，无人声，无长混响。

避免点：

- 不要和金币拾取完全一样，购买成功应更像交易完成。
- 不要太长，商店可能连续操作。

### ShopPurchaseFailed

用途：购买失败，通常是金币不足或条件不满足。

声音结构：

- 起音：短促低频敲击或空响。
- 主体：轻微下行错误提示。
- 尾音：干净收束。

制作提示词：

> 商店购买失败音，短促低音和空钱包感敲击，带轻微下行错误提示，明确但不刺耳，时长 0.25-0.45 秒，无人声，无尖锐警报。

避免点：

- 不要过度负面。
- 不要像角色受伤。

### ShopRerolled

用途：商店刷新商品。

声音结构：

- 起音：快速洗牌或物品滑动。
- 主体：连续短颗粒的切换感。
- 尾音：轻微上扬，表示新商品生成。

制作提示词：

> 商店刷新音，快速洗牌、卡片滑动或物品列表切换声，带轻微上扬收尾，表达商品被重新生成，时长 0.35-0.7 秒，清晰、不杂乱、无语音。

避免点：

- 不要像奖励卡展示音太相似。
- 不要做成金币声。

### ItemEquipped

用途：装备武器或饰品。

声音结构：

- 起音：物品拿起或落位。
- 主体：轻微金属扣合、卡扣、装备装配。
- 尾音：短确认点。

制作提示词：

> 装备物品音，武器或饰品装配到位的金属扣合声，叠加短促确认反馈，稳、清楚、有落位感，时长 0.25-0.5 秒，无人声。

避免点：

- 不要区分武器和饰品。
- 不要太像购买成功。

### ItemSold

用途：出售或回收物品。

声音结构：

- 起音：物品收纳或消失。
- 主体：金币入账或轻快结算。
- 尾音：短小明亮反馈。

制作提示词：

> 出售物品音，物品被回收后金币入账的小型结算声，短促、轻快、明确，时长 0.25-0.5 秒，区别于购买成功，更偏获得货币，无人声。

避免点：

- 不要太像金币拾取的高频连续叮当。
- 不要沉重。

### WeaponMerged

用途：武器合成。

声音结构：

- 起音：两个或多个物体靠拢。
- 主体：金属摩擦、能量融合。
- 尾音：明确完成点。

制作提示词：

> 武器合成音，多个武器汇聚、金属摩擦、短促能量融合，最后有清晰完成闪光，表达合成成功，时长 0.5-0.9 秒，幻想科技感，无人声。

避免点：

- 不要像普通装备音。
- 不要有过长蓄力。

### WeaponLevelUp

用途：武器等级提升。

声音结构：

- 起音：强化启动。
- 主体：上扬能量和金属强化。
- 尾音：明亮完成铃音。

制作提示词：

> 武器升级音，上扬能量声、金属强化声和明亮完成铃音，表达武器变强，时长 0.45-0.8 秒，有成长感但不超过传说卡选择音，无人声。

避免点：

- 不要像玩家升级完全一样。
- 不要太爆裂。

## 掉落与宝箱音效

### CoinCollected

用途：金币被玩家收集。

声音结构：

- 起音：清脆金币碰撞。
- 主体：一到两枚金币轻响。
- 尾音：极短上扬。

制作提示词：

> 金币收集音，清脆明亮的金币碰撞，短、亮、轻快，适合频繁拾取连续播放，时长 0.12-0.3 秒，无人声，无长尾音。

避免点：

- 不要做成一大把金币，频繁播放会吵。
- 不要太低沉。

### ChestOpened

用途：宝箱打开动画开始或完成。

声音结构：

- 起音：箱扣解锁或打开。
- 主体：木箱或金属箱摩擦开启。
- 尾音：短促奖励闪光。

制作提示词：

> 宝箱打开音，箱扣打开、木质或金属箱盖掀开，接短促奖励闪光，表达宝箱开启和奖励出现，时长 0.5-1.0 秒，无人声，无长音乐尾音。

避免点：

- 不要包含宝箱被收集的独立提示。
- 不要像关卡完成音。

## 武器动作音效

### Swipe

用途：通用快速挥动。

声音结构：

- 起音：快速空气切割。
- 主体：轻薄刷过。
- 尾音：几乎没有。

制作提示词：

> 通用快速挥动音，短促空气切割，轻薄、快速、不带明显武器材质，适合高频近战动作，时长 0.12-0.25 秒，无人声，无冲击声。

避免点：

- 不要带命中感。
- 不要太厚。

### Slap

用途：通用近战拍击或直接伤害动作。

声音结构：

- 起音：钝击瞬态。
- 主体：短促拍击感。
- 尾音：很短。

制作提示词：

> 通用近战拍击音，短促钝击、轻微肉感或木质冲击，适合基础直接攻击，时长 0.15-0.3 秒，不血腥、不夸张、无人声。

避免点：

- 不要太像敌人受伤音。
- 不要有明显死亡感。

### SwordSlash

用途：剑类普通挥砍。

声音结构：

- 起音：空气被刀刃切开。
- 主体：轻金属边缘感。
- 尾音：快速消失。

制作提示词：

> 剑类普通挥砍音，空气切割叠加轻微金属边缘声，快速、清楚、利落，时长 0.18-0.35 秒，适合单次普通斩击，无命中声。

避免点：

- 不要包含撞击或受伤。
- 不要过厚，重击另有音效。

### SwordHeavySlash

用途：剑类重击挥砍。

声音结构：

- 起音：较重的挥动起势。
- 主体：厚空气切割、低频摆动。
- 尾音：短促重感收尾。

制作提示词：

> 剑类重击挥砍音，厚重空气切割、低频摆动和较重金属质感，表达大剑或重型斩击，时长 0.3-0.55 秒，无命中声，无人声。

避免点：

- 不要做成 Boss 近战。
- 不要拖成长蓄力。

### DaggerStab

用途：匕首刺击。

声音结构：

- 起音：极短尖锐空气点刺。
- 主体：轻金属刺出。
- 尾音：立即结束。

制作提示词：

> 匕首刺击音，短、尖、快速的点刺声，轻微金属和空气瞬态，适合快速刺击动作，时长 0.1-0.25 秒，无命中声，无血腥声。

避免点：

- 不要有长尾。
- 不要太厚重。

### StaffSwing

用途：法杖挥舞动作。

声音结构：

- 起音：木质杆体快速移动。
- 主体：空气划过，轻微魔法颗粒。
- 尾音：短小闪动。

制作提示词：

> 法杖挥舞音，木质法杖划过空气，叠加轻微魔法粒子闪动，重点表现挥舞动作而非发射，时长 0.18-0.35 秒，无人声，无弹射物飞出声。

避免点：

- 不要做成 `StaffProjectileLaunch`。
- 不要太像剑挥砍。

### StaffProjectileLaunch

用途：法杖发射弹射物。

声音结构：

- 起音：短促魔法聚焦。
- 主体：亮色能量释放。
- 尾音：小型发射尾迹。

制作提示词：

> 法杖弹射物发射音，短促魔法聚能后释放，包含上扬能量、亮色闪光和小型发射瞬态，适合法杖射出投射物，时长 0.3-0.55 秒，无人声，无长蓄力。

避免点：

- 不要像能量枪。
- 不要包含命中或爆炸。

### GunshotLight

用途：轻型枪械射击。

声音结构：

- 起音：短促枪口爆发。
- 主体：清脆机械感。
- 尾音：极短。

制作提示词：

> 轻型枪械射击音，短促、干净、较高频，后坐力轻，适合手枪、冲锋枪等高频射击，时长 0.12-0.28 秒，无弹壳长尾，无环境回响。

避免点：

- 不要过度真实军事化。
- 不要太低频。

### GunshotHeavy

用途：重型枪械射击。

声音结构：

- 起音：强冲击。
- 主体：厚实低中频枪声。
- 尾音：短暂残响。

制作提示词：

> 重型枪械射击音，厚实低频冲击、明显后坐力、短尾音，适合霰弹枪、狙击枪或重型手枪，时长 0.25-0.45 秒，无长环境回声。

避免点：

- 不要持续太久。
- 不要压过 Boss 技能音。

### EnergyShot

用途：能量枪或科技枪射击。

声音结构：

- 起音：合成器脉冲。
- 主体：电流和能量发射。
- 尾音：短促高频收束。

制作提示词：

> 能量枪射击音，短促合成器脉冲、能量电流和明亮发射瞬态，科技感明显，区别于真实枪械，时长 0.2-0.4 秒，无命中声，无长激光持续声。

避免点：

- 不要像 Boss 激光。
- 不要太尖锐。

## 弹射物音效

### GenericProjectileLaunch

用途：无法归类到枪、剑、法杖的通用弹射物发射。

声音结构：

- 起音：轻量推出。
- 主体：空气或小能量释放。
