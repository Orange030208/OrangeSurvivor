# 2D 割草游戏

这是一个基于 Unity 引擎开发的 2D 割草风格（Survivor-like）游戏项目。

## 项目概述
本项目旨在实现一个典型的 2D 割草游戏核心玩法，包括玩家控制、敌人 AI 以及后续的技能升级系统。目前项目处于基础开发阶段，已初步集成了一些核心插件和基础脚本。

## 核心功能
- **玩家控制**：基础的玩家移动控制架构。
- **敌人系统**：敌人会自动追踪玩家位置并尝试进行攻击。
- **环境搭建**：使用 Unity URP（通用渲染管线）进行开发。

## 已集成插件/资源
- **DOTween**: 用于流畅的补间动画效果。
- **TotalJSON**: 高效的 JSON 处理库。
- **Tabsil**: 游戏开发工具集。
- **Kawaii Survivor**: 2D 游戏资源素材。
- **Mobile Joystick**: 移动端摇杆控制支持。

## 开发规范
- 使用 **URP** 渲染管线。
- 遵循 **SOLID** 原则进行代码设计。
- 核心逻辑位于 `Assets/Scripts` 目录下。

## 如何运行
1. 使用 Unity 2022.3 或更高版本打开项目。
2. 确保已配置 URP 设置（位于 `Assets/Settings`）。
3. 打开 `Assets/Scenes/SampleScene.unity` 场景。
4. 点击 Play 开始游戏。
